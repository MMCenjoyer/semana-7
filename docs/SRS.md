# SRS - Sistema de préstamos de biblioteca estudiantil (v1.1)
| ID | Requisito |
|----|-----------|
| RF-01 | El sistema permitirá buscar libros por título. |
| RF-02 | El sistema permitirá registrar el préstamo de un libro disponible, respetando el límite de RB-01. |
| RF-03 | El sistema permitirá registrar la devolución de un libro. |
| RF-04 | El sistema permitirá consultar los préstamos activos de un estudiante. |
| RF-05 | El sistema impedirá el cuarto préstamo activo de un estudiante. |

**RB-01:** máximo tres préstamos activos por estudiante; los devueltos no cuentan.
