# SRS - Sistema de préstamos de biblioteca estudiantil (v1.0)
| ID | Requisito |
|----|-----------|
| RF-01 | El sistema permitirá buscar libros por título. |
| RF-02 | El sistema permitirá registrar el préstamo de un libro disponible. |
| RF-03 | El sistema permitirá registrar la devolución de un libro. |
| RF-04 | El sistema permitirá consultar los préstamos activos de un estudiante. |
